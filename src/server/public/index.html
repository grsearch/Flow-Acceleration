用于排除过晚、过热、价格已经跳升或手工禁止的币。过滤只影响模拟开仓，原始信号仍保留。

这些字段只使用信号发生时已经可见的数据，适合做样本外验证，不包含未来 Smart Wallet 行为。

3 · 动态卖出策略
