# 实盘空代币账户回收与资金核算

## 本次变更

- RUG 采集器先于实盘管理器完成启动；反馈模块动态解析采集器，缺失、禁用或采证错误会显示不就绪。不会事后用新行情伪造旧入场证据。
- 原交易现金盈亏保留。新增账户留存资金、经济盈亏、退款、回收手续费和回收后现金盈亏。证据不足显示未知，不把“未知”当零。
- 自动关闭本程序已验证买入所创建、完全卖空的规范 ATA，将账户中的 SOL 退回同一个交易钱包。
- 不改变 LEGACY 的 0.02 SOL、3 仓、现有止损/移动止盈/最长持仓参数；本次没有因此启用其他策略。

## 何时自动执行

默认启用 FLOW_LIVE_ACCOUNT_RECOVERY_ENABLED=true，仅在 LIVE 模式工作；无需额外定时服务。

每 60 秒后台运行一轮，最多处理 3 个回收候选，另扫描至多 3 条历史订单补齐完整链上资金证据。不是每次买入前扫描钱包；旧订单按 ID 固定小页推进。回收不加入紧急 SELL 指令，不因关闭失败阻止卖出。

历史订单使用数据库已保存签名查询回执；不扫描整个钱包，也不关闭手工持仓的账户。候选建立后至少等待 60 秒，且必须没有该 mint 的活动仓位或未处理交易。历史订单多时需要多轮，不能保证所有旧账户在首次启动即完成。

## 发送前的硬校验

1. 买入回执已证明账户由本钱包支付创建，账户地址/币/程序/创建签名完全匹配。
2. 重新读取 finalized 创建回执和当前账户。只允许普通 Token 账户，以及仅含 ImmutableOwner 的 Token-2022 账户；排除 WSOL、非规范账户和危险扩展。
3. 当前代币余额严格为 0，无委托余额、异常状态或他人控制的关闭权限。退款收款人固定为同一个交易钱包。
4. 当前账户资金与创建时一致；查询该账户至多 32 条近期交易，要求能看到创建签名，且中间没有关闭重建或资金异常。证据不足不关闭，不进行无限历史扫描。
5. 同 mint 未决回收时不允许另一笔关闭或新开仓。链上 CloseAccount 也会原子拒绝非零余额；与手工转入发生竞态时宁可失败，不能烧币。
6. 关闭交易优先费 0.0001 SOL，总网络费校验不超过 0.000105 SOL，且费用必须小于可回收资金。

## 持久化、超时与关闭开关

发送前先把完整已签交易、签名和账户身份同步持久化并回读，之后才广播。发送超时保留原签名，只查询确认，不重签、不自动再发一笔扣费交易。只有 finalized 回执或严格证明过期后才释放该 mint 的回收锁。

FAILED、明确过期及不安全候选进入 BLOCKED，不自动反复扣手续费；不确定结果保持 UNKNOWN 并保留锁。若程序重启，先恢复全部持久未决锁，再允许新开仓。RPC 单项维护操作最多等待 30 秒，超时任务停止继续历史查询或签名。

设 FLOW_LIVE_ACCOUNT_RECOVERY_ENABLED=false 后不再准备或发送新关闭交易；已有未决签名仍只读核对，直到能够安全解除锁。LIVE 全局安全锁、紧急开关、正在开仓/出仓都会暂停新的回收准备；止损和卖出不受回收锁限制。

## 金额如何展示

- 原交易现金盈亏：原 BUY/SELL 钱包余额变化，保持原有对账语义。
- 账户留存资金：完整回执已验证仍占用的目标代币账户 SOL；不是不可回收手续费。
- 经济盈亏：原现金盈亏 + 已验证账户净投入 - 额外回收交易费用。
- 回收后现金盈亏：原现金盈亏 + 实际回收交易钱包净变化。
- 退款不会再次叠加到经济盈亏。共享 ATA 仅归属实际出资创建的仓位；重复回执不重复计费。
- 原现金亏损触发 RUG 大亏筛选的口径本次不静默更改；RUG 判定仍须独立因果证据，不能直接把账户占用资金或普通亏损当恶意行为。
- 历史原始订单缺完整回执时，全体经济盈亏显示待验证，同时显示已验证子集与覆盖数，避免只展示盈利子集。

使用已有安全更新流程，保持单实例，不另行 nohup/npm start 启动，不手工改数据库或覆盖源码。部署前保留当前正常持仓退出能力。

查看 /api/health 的 liveTrading：
- lossRugFeedback.ready=true，captureReady/analyzerReady/learningReady=true；新交易 entryEvidenceUnavailable 不应继续增加。
- accountRecovery.enabled=true、ready=true，runs/receiptsBackfilled/prepared/confirmed 随实际符合条件的样本推进。
- accountFunding.errors 不应持续增加。
- pendingMintLocks 非零时查看对应 UNKNOWN/PREPARED 原签名；不能靠清表、删锁或重签“解决”。

Live Trading 详情中的账户回收区展示留存资金、退款和逐项状态；BLOCKED/ABSENT 未归因时不伪造退款。导出会包含相关回收记录和关联订单，以便下次审计。

本次只是代码实现和离线测试，没有部署、没有回收真实资金。账户关闭后链上数据不能“取消”，因此上线后应先核对首笔退款签名及收款钱包。
